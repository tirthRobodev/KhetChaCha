# Animation Assets Directory

This folder is reserved for optional local animation assets (e.g., Lottie JSON, Rive files, or custom SVG illustrations) for the KhetChacha application.

The first screen (Splash Screen) currently renders a rich, high-performance, responsive Indian agricultural scene using Flutter's built-in `CustomPainter` and `AnimationController` for 100% offline and standalone operation with zero external dependencies.
